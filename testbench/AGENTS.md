# Agent Instructions

Read `CONTEXT.md` before planning or changing the product. Preserve the factory
flash backup and do not store Wi-Fi credentials, Hermes tokens, private keys, or
certificate material in this project.

Use the macOS simulator before hardware flashing when a change can be exercised
through the shared UI module. Keep board support, product UI, voice transport,
and Hermes integration behind separate interfaces.
