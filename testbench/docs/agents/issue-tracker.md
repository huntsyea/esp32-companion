# Issue Tracker

This project has no Git remote or external issue tracker. Project work is
published as local Markdown under `.scratch/<effort>/`.

Each issue is one Markdown file with YAML front matter containing:

- `title`
- `type`
- `status`
- `labels`

Specifications use `type: specification`. Keep one effort in one directory and
use stable descriptive filenames. Do not copy completed issues into a second
tracker unless the repository later adopts one through an ADR.
