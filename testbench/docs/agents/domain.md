# Domain Documentation

`CONTEXT.md` is the canonical glossary, product boundary, current-state summary,
and invariant list for this single-product repository.

Durable architectural decisions belong in `docs/adr/`. Research evidence may
remain in `docs/research/`, but research notes do not override the context or an
accepted ADR.

Update `CONTEXT.md` when product vocabulary or invariants change. Create an ADR
when a durable architecture choice changes component ownership, protocol
compatibility, security boundaries, or dependency direction.
