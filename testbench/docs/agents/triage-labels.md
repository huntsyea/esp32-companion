# Triage Labels

The local tracker uses these labels without aliases:

| Label | Meaning |
| --- | --- |
| `needs-triage` | The issue has not been assessed. |
| `needs-info` | Work cannot start because required information is missing. |
| `ready-for-agent` | The issue is specific enough for an implementation agent. |
| `ready-for-human` | The issue requires a human decision or physical action. |
| `wontfix` | The issue is intentionally declined. |

Use one readiness label at a time. Other descriptive labels may be added only
when they improve retrieval and do not duplicate this vocabulary.
